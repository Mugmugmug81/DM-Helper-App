The Book of Boundless Beginnings

During the down time caused by my layoff, I realized I need to keep my skills sharp and prehaps even learn some new things.  That was the genesis of this project.  I created an app that would allow a DM (dungeon master) to create an entire campaign in one place.  Monsters, maps, npcs, pcs, etc...
This script uses geographic specific algorithms that mimic particular biomes.  The rigid, grid-like, structre of a city or the natural flowing and fractical based creations found in nature.
I use Streamlit to host this app, and it is functional on both mobile and PC devices
You can access the app here, https://dm-apper-app-b6krtqpqx4vwjilyuze7m7.streamlit.app/
